# OneFrame

Улучшения стандартных групповых и рейдовых рамок The Elder Scrolls Online: роли, здоровье, щиты, Ultimate, сортировка и статистика боя.

Автор: **oneDOK**. Версия: **1.0**. ESO API: **101050, 101051**.

## Установка

Скачайте репозиторий через **Code → Download ZIP** и скопируйте папку `OneFrame` в `Documents/Elder Scrolls Online/live/AddOns/`. Установите **LibAddonMenu-2.0**, включите аддон и выполните `/reloadui`.

**HodorReflexes** и **LibGroupCombatStats** необязательны и используются для общей статистики. Подробнее: [README аддона](OneFrame/README.md).
