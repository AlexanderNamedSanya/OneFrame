# OneFrame 26.1

Changes since 1.2:
- Adopted year-based versioning (YY.BUILD), starting with 26.1.
- No functional changes since release 1.2.

Installation: extract the OneFrame folder into your ESO AddOns directory. LibAddonMenu-2.0 is required.

Validation: existing successful release 1.2 automated checks were reused because addon behavior is unchanged. Version metadata, manifest paths and archive contents were verified for this release. In-game ESO validation has not been performed.
